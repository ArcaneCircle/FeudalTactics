# Feudal Tactics (webxdc port)

A webxdc port of [Feudal Tactics](https://github.com/Sesu8642/FeudalTactics):
a small medieval strategy game on a random hex island,
with rules inspired by Sean O'Connor's _Slay_.

The rules, map generation and enemy AI are taken from the original
GPL-3.0-or-later Java source and reimplemented to run in a browser.

This port adds enhanced graphics and extra features:
a list of challenges shared in the chat,
and a daily challenge.

## Controls

| Action                                     | Touch / mouse                                        | Keyboard               |
| ------------------------------------------ | ---------------------------------------------------- | ---------------------- |
| Select kingdom / pick up / place / conquer | tap a tile (tap a second time on a stack to combine) | —                      |
| Buy peasant                                | person button, or right-click, or long-press         | `1`                    |
| Buy tower                                  | tower button, or middle-click                        | `2`                    |
| End turn                                   | arrow button                                         | `e`                    |
| Undo                                       | arrow-left button                                    | `Ctrl+Z` / `Backspace` |
| Pan / zoom                                 | drag / pinch or wheel                                | —                      |

Double-tap an empty tile of the selected kingdom to buy **and** place a peasant at once.
